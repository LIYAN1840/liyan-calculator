黎岩的计算器 PWA 安装向导

《黎岩的计算器》PWA 超详细安装向导

这份向导按“第一次接触 GitHub 也能完成”的方式编写。请不要跳步骤。遇到问题时，先看最后的“常见问题排查”。

一、你最终会得到什么

完成后，你会有：

  1. 一个公开的网址，例如：https://你的用户名.github.io/liyan-calculator/
  2. 一个能在浏览器里直接使用的计算器。
  3. 一个能安装到 Windows、macOS、Android、iPhone 或 iPad 主屏幕的 PWA 应用。
  4. 首次成功联网打开后，即使暂时断网，计算器通常仍可继续使用。

PWA 可以理解为“用网页技术做成、但可以像普通应用一样安装”的程序。你不需要购买服务器，也不需要安装编程软件。

二、开始前要准备什么

请准备：

  • 一台能上网的电脑。
  • 一个电子邮箱。
  • 一个 GitHub 账号。
  • 本压缩包：黎岩的计算器-PWA-GitHub-Pages.zip。
  • 推荐浏览器：Microsoft Edge 或 Google Chrome。

还没有 GitHub 账号怎么办

  1. 打开 https://github.com/。
  2. 点击右上角 Sign up（注册）。
  3. 按网页提示输入邮箱、密码和用户名。
  4. 到邮箱里完成验证。
  5. 回到 GitHub 登录。

请记住你的 GitHub 用户名。后面的网站地址会用到它。

三、先解压压缩包

Windows 电脑

  1. 在“下载”文件夹找到 黎岩的计算器-PWA-GitHub-Pages.zip。
  2. 用鼠标右键点击压缩包。
  3. 点击 全部解压。
  4. 保持默认位置，点击 提取。
  5. 打开解压后的文件夹。

macOS 电脑

  1. 在“下载”文件夹找到压缩包。
  2. 双击压缩包。
  3. 系统会自动生成同名文件夹。
  4. 打开这个文件夹。

解压后应该看到什么

文件夹中应当有：

  • index.html
  • manifest.webmanifest
  • service-worker.js
  • README.md
  • 安装向导.md
  • 安装向导.html
  • .nojekyll
  • icons 文件夹

icons 文件夹里应有 5 张 PNG 图片。

非常重要：后面要上传的是“解压后的这些文件和文件夹”，不是把 ZIP 压缩包本身上传进去。

四、在 GitHub 新建仓库

“仓库”可以理解为 GitHub 上用来放网站文件的文件夹。

  1. 登录 https://github.com/。
  2. 点击页面右上角的 + 号。
  3. 点击 New repository（新建仓库）。
  4. 在 Repository name 中输入：liyan-calculator
  5. 在 Description 中可以输入：黎岩的计算器 PWA
  6. 选择 Public（公开）。
  7. 如果页面上有 Add a README file，不要勾选。
  8. .gitignore 保持 None。
  9. License 保持 None。
  10. 点击绿色的 Create repository。

为什么建议选 Public

GitHub 免费账号最容易用公开仓库发布 Pages。公开意味着别人可能看到网页源文件，但不会看到你的 GitHub 密码、电脑文件或计算器历史记录。计算历史只保存在使用者自己的浏览器中。

五、把网页文件上传到仓库

创建仓库后，你会看到一个新页面。

  1. 找到页面中的 uploading an existing file 链接并点击。
  2. 回到电脑上刚才解压出来的文件夹。
  3. 选中里面的所有文件和 icons 文件夹。
  4. 把选中的内容拖到 GitHub 页面中虚线框区域。
  5. 等待上传进度结束。
  6. 仔细查看文件列表，确认至少有：
    • index.html
    • manifest.webmanifest
    • service-worker.js
    • icons/icon-192.png
    • icons/icon-512.png
  7. 页面下方找到 Commit changes 区域。
  8. 在说明框中输入：首次上传计算器 PWA
  9. 点击绿色的 Commit changes 按钮。
  10. 等待页面返回仓库首页。

如果没有看到 .nojekyll

不用紧张。某些电脑会隐藏以英文句点开头的文件。这个项目没有需要 Jekyll 处理的内容，即使暂时没上传 .nojekyll，其他文件齐全时通常也能运行。

上传后最容易犯的错误

  • 错误：仓库里只有一个 ZIP 压缩包。
  • 正确：仓库首页能直接看到 index.html 和其他文件。
  • 错误：所有文件又被套在一个额外文件夹里。
  • 正确：index.html 就在仓库最外层，也就是根目录。

六、开启 GitHub Pages

  1. 在仓库页面顶部点击 Settings（设置）。
  2. 如果看不到 Settings，点击顶部的 … 或下拉菜单再找 Settings。
  3. 在左侧菜单找到 Code and automation。
  4. 点击其中的 Pages。
  5. 找到 Build and deployment。
  6. 在 Source 下拉框选择 Deploy from a branch。
  7. 在 Branch 下拉框选择 main。
  8. 旁边的文件夹下拉框选择 / (root)。
  9. 点击 Save。

保存后，GitHub 会开始发布网站。通常需要 1～5 分钟；第一次偶尔会更久。

怎么知道发布成功了

  1. 等一两分钟后刷新 Pages 设置页。
  2. 成功后页面上方会出现类似文字：Your site is live at ...
  3. 点击后面的 Visit site，或直接点击显示的网址。

如果你的用户名是 zhangsan，仓库名是 liyan-calculator，网址通常是：

https://zhangsan.github.io/liyan-calculator/

请把 zhangsan 换成你自己的 GitHub 用户名。

不要把仓库文件页面 github.com/用户名/仓库名 当作计算器网址。真正的网站一般是 用户名.github.io 开头。

七、第一次打开后先做检查

打开网站后，请依次检查：

  1. 页面标题是不是“黎岩的计算器”。
  2. 输入 1 ÷ 3，结果是不是一个受控长度的小数。
  3. 做几次计算，历史记录是否出现。
  4. 点击“清空记录”，历史是否清除。
  5. 手机横屏、竖屏旋转后，页面是否能恢复。
  6. 浏览器标签或安装窗口里是否出现“黎”字图标。

检查离线功能

  1. 必须先在有网络时成功打开网站一次。
  2. 等待约 10 秒，让浏览器完成缓存。
  3. 不要关闭浏览器标签。
  4. 临时断开 Wi-Fi 或网络。
  5. 刷新网页。
  6. 如果仍能打开并计算，说明离线功能正常。

历史记录保存在当前浏览器里。换电脑、换浏览器、清除浏览器数据后，历史记录不会自动同步。

八、在 Windows 电脑安装

推荐使用 Microsoft Edge 或 Google Chrome。安装后，计算器会出现在“开始”菜单中，并可固定到任务栏。

方法 A：Microsoft Edge

  1. 用 Edge 打开你的 GitHub Pages 网站地址。
  2. 等网页完全显示。
  3. 点击右上角 …。
  4. 点击 应用（Apps）。
  5. 点击 将此站点安装为应用（Install this site as an app）。
  6. 名称保持“黎岩的计算器”。
  7. 点击 安装。
  8. 如果出现“固定到任务栏”“固定到开始菜单”“创建桌面快捷方式”等选项，可按需要勾选。
  9. 点击 允许 或 完成。

方法 B：Google Chrome

  1. 用 Chrome 打开网站。
  2. 看地址栏右侧是否有“安装”图标；如果有，直接点击。
  3. 如果没有，点击右上角 ⋮。
  4. 找到 投放、保存和分享（Cast, save, and share）。
  5. 点击 将网页安装为应用（Install page as app）。
  6. 点击 安装。

找不到安装按钮时

请确认：

  • 打开的是 https://...github.io/... 网站，不是本地文件。
  • 网站地址左侧没有“不安全”警告。
  • 你已经刷新过一次并等待几秒。
  • manifest.webmanifest、service-worker.js 和 icons 文件夹都已上传。
  • 浏览器不是很旧的版本。

九、在 macOS 电脑安装

使用 Chrome

  1. 用 Chrome 打开网站。
  2. 点击地址栏右侧的安装图标；或者点击右上角 ⋮。
  3. 选择 投放、保存和分享。
  4. 选择 将网页安装为应用。
  5. 点击 安装。
  6. 安装后可从“应用程序”或启动台中打开。

如果使用 Safari，菜单名称可能随 macOS 版本变化。最稳妥的方式是先用最新版 Chrome 完成 PWA 安装。

十、在 Android 手机上安装

推荐使用 Google Chrome。

  1. 在手机 Chrome 中打开你的 GitHub Pages 网站。
  2. 等待网页完全打开。
  3. 点击右上角 ⋮。
  4. 点击 安装应用，或点击 添加到主屏幕。
  5. 如果出现安装确认窗口，点击 安装。
  6. 回到手机主屏幕，找到带“黎”字图标的“黎计算器”。
  7. 点击图标打开，确认顶部没有普通浏览器地址栏，说明它以应用方式运行。

有些 Android 手机会先显示“创建快捷方式”，这也可以使用；不同手机品牌的文字可能略有不同。

十一、在 iPhone 或 iPad 安装

推荐使用 Safari。

  1. 打开 Safari。
  2. 输入你的 GitHub Pages 网站地址并打开。
  3. 点击 Safari 的 分享 图标，也就是“方框上面有一个向上箭头”的按钮。
  4. 在弹出的菜单中向下滑动。
  5. 点击 添加到主屏幕。
  6. 如果看到 作为网页 App 打开（Open as Web App），请保持开启。
  7. 名称保持“黎计算器”或“黎岩的计算器”。
  8. 点击右上角 添加。
  9. 回到主屏幕，找到“黎”字图标。
  10. 点击图标打开。

如果菜单里没有“添加到主屏幕”：

  1. 滑到分享菜单最下方。
  2. 点击 编辑操作。
  3. 找到“添加到主屏幕”并加入常用操作。
  4. 返回后再次尝试。

十二、以后怎样更新计算器

当你拿到新版 PWA 压缩包时：

  1. 先解压新版压缩包。
  2. 打开原来的 GitHub 仓库。
  3. 点击 Add file。
  4. 点击 Upload files。
  5. 把新版中的全部文件和 icons 文件夹拖进去。
  6. GitHub 会识别同名文件并准备覆盖。
  7. 在提交说明中输入：更新计算器版本
  8. 点击 Commit changes。
  9. 等待 GitHub Pages 重新发布。
  10. 打开网站并刷新。

已安装的 PWA 通常会自动获取更新。如果仍显示旧页面：

  1. 完全关闭已安装的计算器。
  2. 在浏览器中打开网站并刷新两次。
  3. 等待十几秒。
  4. 再打开已安装的应用。
  5. 仍不更新时，可以卸载 PWA 后重新安装；历史记录可能随浏览器数据清理而消失。

十三、怎样卸载

Windows Edge 或 Chrome

  1. 打开已安装的计算器。
  2. 点击窗口右上角的菜单按钮。
  3. 找到 卸载“黎岩的计算器”。
  4. 确认卸载。

Android

  1. 长按主屏幕上的“黎”字图标。
  2. 点击 卸载 或拖到卸载区域。

iPhone 或 iPad

  1. 长按主屏幕上的“黎”字图标。
  2. 点击 移除 App。
  3. 点击 删除 App 或 从主屏幕移除。

十四、常见问题排查

1. 网站显示 404

按顺序检查：

  1. Pages 设置中的 Source 是否为 Deploy from a branch。
  2. Branch 是否选择 main。
  3. 文件夹是否选择 / (root)。
  4. 仓库根目录是否有 index.html。
  5. 是否等待了几分钟。
  6. 网站地址中的用户名和仓库名是否完全正确。

2. 页面能打开，但没有“黎”字图标

检查仓库里是否有：

  • icons/icon-180.png
  • icons/icon-192.png
  • icons/icon-512.png
  • icons/icon-maskable-512.png
  • manifest.webmanifest

文件名大小写必须完全一致。

3. 页面能打开，但不能离线

  1. 确认用的是 https:// 网站地址。
  2. 有网络时先打开一次并等待 10 秒。
  3. 刷新一次后再测试断网。
  4. 不要在浏览器“无痕模式”中测试。
  5. 确认仓库根目录有 service-worker.js。

4. 浏览器没有安装选项

  1. 先刷新网页。
  2. 等待 10 秒。
  3. 使用最新版 Edge 或 Chrome。
  4. 确认不是在 GitHub 文件预览页。
  5. 确认网站没有 404 文件。
  6. iPhone/iPad 请从 Safari 的分享菜单选择“添加到主屏幕”。

5. 上传后还是旧版本

这是离线缓存还没有更新造成的。可以：

  1. 等 GitHub Pages 发布完成。
  2. 关闭所有计算器页面和应用窗口。
  3. 重新打开网站。
  4. 按 Ctrl + F5 强制刷新（macOS 可尝试 Command + Shift + R）。
  5. 再关闭并重新打开应用。

6. 历史记录消失了

历史记录只存在本机浏览器中。以下情况可能清除它：

  • 清理浏览器数据。
  • 使用无痕模式。
  • 换浏览器或换设备。
  • 卸载应用时同时选择清除数据。

7. 我把 ZIP 上传到了仓库，但网页打不开

GitHub Pages 不会自动把 ZIP 里面的文件当网页运行。请删除或保留 ZIP 均可，但必须把 ZIP 解压后的 index.html 等文件单独上传到仓库根目录。

十五、安全与隐私说明

  • 这个计算器不需要登录。
  • 计算内容和历史记录不会上传到 GitHub。
  • 历史记录使用浏览器本地存储保存。
  • GitHub 仓库公开时，任何人都能看到网页代码和图标，这是静态网站的正常情况。
  • 不要把密码、身份证号码、银行卡资料或其他私人文件放进仓库。
