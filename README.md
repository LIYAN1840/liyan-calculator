# 黎岩的计算器 PWA

这是一个可部署到 GitHub Pages、可安装到电脑和手机、首次联网后可离线使用的计算器。

## 第一次使用请看这里

请打开仓库中的 **[安装向导.md](安装向导.md)**，从第一步开始操作。向导专门按零基础用户编写。

## 文件说明

- `index.html`：计算器网页主程序
- `manifest.webmanifest`：PWA 名称、图标和启动方式
- `service-worker.js`：离线缓存程序
- `icons/`：各尺寸“黎”字应用图标
- `.nojekyll`：让 GitHub Pages 直接发布静态文件
- `安装向导.md`：详细部署、安装、更新和排错说明
- `安装向导.html`：可双击打开的图文式向导网页

> 注意：PWA 安装和离线功能需要从 HTTPS 网站打开。直接双击本地 `index.html` 可以计算，但不能完成正式的 PWA 安装。
